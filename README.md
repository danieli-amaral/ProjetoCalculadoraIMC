# 🧮 Projeto Calculadora de IMC

Este projeto consiste no desenvolvimento de uma calculadora de Índice de Massa Corporal (IMC), utilizando a linguagem Java.

O objetivo foi colocar em prática os conhecimentos adquiridos durante meus estudos em programação, desenvolvendo uma aplicação simples e funcional para calcular e classificar o IMC de um usuário.

## 🚀 Funcionalidades

- Solicita o peso do usuário.
- Solicita a altura do usuário.
- Realiza o cálculo do IMC automaticamente.
- Apresenta o resultado com duas casas decimais.
- Classifica o resultado de acordo com as faixas de IMC.
- Exibe as informações por meio de janelas interativas.

## 🛠️ Tecnologias e conceitos utilizados

- Java
- JOptionPane para entrada e exibição de dados.
- Variáveis do tipo `double`.
- Conversão de dados com `Double.parseDouble()`.
- Formatação numérica com `String.format()`.
- Estruturas condicionais `if`, `else if` e `else`.
- Classe `Locale` para padronização decimal.
